## Known performance risk

The median mobile lab LCP is 2,592 ms, which is 92 ms above the 2.5-second release target. The LCP element is the introductory delivery paragraph, not an image.

Lighthouse measured approximately 16 ms server response time and 257 ms element render delay, with no estimated LCP savings from render-blocking resources or the LCP breakdown. Non-visible page optimizations are already applied, SEO is 100, CLS is negligible, and functional, accessibility and security checks pass.

Further material reduction would require a visible above-the-fold change or delaying the required cookie consent UI. Those changes were not made because they conflict with the approved page design and project rules.

Monitor real-user mobile LCP after deployment. Revisit the above-the-fold layout only if field LCP remains above 2.5 seconds.
