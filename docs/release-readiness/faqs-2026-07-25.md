## Known performance risk

The mobile lab LCP is above the 2.5-second release target. Browser observation identified the first, initially open FAQ answer as the LCP element. Non-visible font preload changes were tested and reverted because they did not improve the result.

Further material improvement would require a visible above-the-fold change, such as initially closing the first answer or changing its layout, or delaying the required cookie consent UI. Those changes were not made because they conflict with the approved page experience and project rules.

Monitor real-user mobile LCP after deployment using field data. Revisit the initial accordion state or above-the-fold layout if field LCP remains above 2.5 seconds.
